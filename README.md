PROJETO   ARVORE 2-3

Este projeto implementa uma Árvore 2-3 em Java, respeitando as restrições da disciplina: sem uso de arrays, listas, estruturas prontas ou bibliotecas auxiliares.

DESCRIÇÃO

A Árvore 2-3 é uma estrutura de dados balanceada que:
- Armazena 1 ou 2 chaves por nó.
- Possui até 3 filhos por nó.
- Mantém todas as folhas no mesmo nível automaticamente.

FUNCIONALIDADE IMPLEMENTADAS

- Inserção de valores com divisão de nós.
- Busca por valores.
- Remoção lógica de chaves.
- Impressão da árvore em ordem.
- Visualização estruturada da árvore (`desenhar()`).

COMO EXECUTAR

1. Compile todos os arquivos:

javac *.java

2. Execute a main:

java Main
